# CaseLawIndia

An Indian case-law research interface for Supreme Court and High Court judgments, built with React, TypeScript, Express, PostgreSQL, and Drizzle ORM.

The local demo imports a bounded set of complete judgments from the Open India Law corpus. Run `npm run import:case-law` to refresh it, `npm run dev` to develop, and `npm run build` for production.

## Attribution

Structured Indian primary-law data from the [Open India Law corpus by Vaquill AI](https://github.com/Vaquill-AI/open-india-law), used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Underlying judgment text remains subject to its originating government/court terms and applicable Indian law.

Open India Law is a point-in-time corpus and may contain omissions or extraction errors. Preserve court, stable case ID, source URL, dataset shard, snapshot version, and import timestamp. Always verify a judgment against its official source before relying on it.
